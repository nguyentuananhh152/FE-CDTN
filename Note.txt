i18n:
- install
    npm install i18next react-i18next --legacy-peer-deps
    npm install --save-dev i18next-parser --legacy-peer-deps

- Tạo file i18next-parser.config.js ở thư mục gốc với nội dung sau:
    module.exports = {
        locales: ['en', 'vi'],
        output: 'src/i18n/locales/$LOCALE.json',
        input: [
            'src/**/*.{js,jsx}',
        ],
        defaultValue: '',
        keySeparator: false,
        namespaceSeparator: false,
    };

- Tạo folder output:
    mkdir -p src/i18n/locales

- Tạo file output
    vi.json
    en.json

- Chạy lệnh sau để quét toàn bộ code và sinh file en.json, vi.json:
    npx i18next 'src/**/*.{js,jsx}'
      npx i18next --config i18next-parser.config.js 'src/**/*.{js,jsx}'
